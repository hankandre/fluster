# T2-02: Extract the core into packages/core

- Domain: Process (the task's `domain`). The move touches Playback Negotiation, Playback Session, Playstate Reporting, Security & Redaction, Server Connection & Identity and Catalog code without changing it (`DOMAINS.md`).
- Implementer: **`implementer`**. All of the work is TypeScript, Node scripts, configs and docs. Nothing goes under `modules/` or `apps/tv/android/`. The PlayerEngine port file `src/domain/playback.ts` is renamed byte for byte to `packages/core/src/domain/playback.ts`: it imports only `./` siblings (`grep` of `src/domain/*.ts`), so the port's interface and content do not change. For that reason this spec sets `touchesNative=false`. The spec-checker may overrule this. The task's `model` is `opus`, so the coordinator should start the run with `models: { implement: { routine: "opus" } }`. The guardian review still runs, because the moved paths match `HIGH_RISK_PATH` (`packages/core/.*(jellyfin|player|playback|redact|…)`).
- Depends on: T1-05, T1-06, T1-09, T1-11 and T1-12, all `done` with `passes: true` on origin/main at `af6ac3a` (`node scripts/task.mjs show <id>`).
- Risk: high in reach (every core file moves, and so do the tests, fixtures, lint, type-check and test wiring), low in behavior (no runtime code changes). There is no playback, network, token or native behavior change, so **no Jellyscale wire test applies** (`pnpm tv:wire` is T3-05). The server tripwire is still run, because its imports change.
- No plan file exists (`docs/plans/` is absent). This spec carries the milestones and the decision log.

## Goal

Make the repository a pnpm workspace and move the platform-free TypeScript core into one package, `@octave/core` at `packages/core`, so that `apps/tv` (T3-01) and later hosts consume one package. The domain, the Jellyfin gateway and negotiation, the coordinator, the playstate reporter, redaction and safe reasons move with all of their tests and fixtures. The move must:

- change no behavior;
- run every core test in Node;
- point the import-boundary lint at the package and tighten it to what the acceptance says;
- keep `git log --follow` working for every moved file;
- land as one PR while no other task is in progress.
