## Goal

Hook dependency arrays, which the player relies on, are checked by nothing today, and two `eslint-disable-next-line react-hooks/exhaustive-deps` comments claim a lint that does not run (triage §2 "Problem 4"). Unused locals and parameters are flagged in `tsconfig.integration.json` but not in the app. Add ESLint with exactly the two classic React hooks rules as errors over `src/`, turn on `noUnusedLocals` and `noUnusedParameters` in `tsconfig.app.json`, fix what both report, and run both in `pnpm check` and in CI.

### 4. Fix the hook findings

Rules for any finding: prefer a fix that keeps the same effect and callback timing; adding a dependency that changes identity every render, or that changes when an effect runs, needs either a test of the new timing or a disable line with a one-line reason. Never wrap a value in `useMemo`/`useCallback` in a caller just to silence the rule unless it is the clear fix.

- **`PlayerView.tsx:179-182`.** `const wakeChrome = visibility.wake;` then `useCallback((target) => { wakeChrome(); focusChromeControl(region.current, target); }, [wakeChrome])`. Same dependency, same identity, no behaviour change.
- **`use-auto-play-next.ts` `playNow`.** Add `const latestAdvance = useRef(advance);` and an effect with no deps array that sets `latestAdvance.current = advance;` (the pattern of `use-escape-key.ts:18`). `playNow` calls `go(() => latestAdvance.current(next))`, deps `[go, next]` unchanged: the destination reads the ref when it runs, after the `stopAndLeave` await, not when `playNow` is called. `playNow` keeps its identity across renders, so the countdown effect runs exactly when it does today; the advance that runs is the latest one. Do not memoize `advanceTo` in `src/features/player/index.tsx`; the hook should not depend on its caller's memoization. Do not use `useEffectEvent`: `playNow` is also called from a button and the `n` key, and functions from `useEffectEvent` may only be called from effects.
- **`settings.tsx:134`.** Disable line with the reason in Files to touch. Do not add `value` (it would refocus the heading when the section changes while open).
- **`ambient-backdrop.tsx:61`.** Delete the directive.
- **`player-sheet.tsx:60-61`.** Merge the reason into the directive.

Commit: `fix(player): satisfy hook dependency lint without changing effect timing (P0-16)`, with the new test.
