# P17-03: Choose audio and subtitle languages in Settings

- Task: `P17-03` in `tasks/prd.json` (phase P17, domain Server Connection & Identity, model sonnet, skill `jellyfin-api`, `human: false`).
- Depends on: `P17-01`, `P17-02`, `P13-17`, `P13-20`, all `done` with `passes: true` on `origin/main` (`df9976b`).

- Risk: medium. This is the first write to the viewer's Jellyfin account. Jellyfin replaces the whole `Configuration` on every save, so a careless body resets 14 other fields in every app the viewer uses (P17-01, `configuration-sequence`). **A `guardian` review is required** (acceptance 11).

The exact choices are fixed after P17-01.

- **Supported servers are 10.11.0 and later** (`src/domain/server-version.ts` `MINIMUM_SERVER_VERSION`; the gateway refuses older servers at `connect`, `gateway.ts:245`).

## Goal

Settings gains a **Languages** section where the viewer sets the audio and subtitle languages that their Jellyfin account uses to pick the starting tracks. Each row is one Picker in plain words that writes the two account fields it needs, so a choice always has the effect it names. The values live on the Jellyfin account, the rows say so, and Fluster stores nothing about them on the computer. The save reads the account's `Configuration` fresh, changes only the row's two fields, and posts every other field back exactly as read. The detail page's subtitle list (P17-02) follows a change at once. The "Subtitle languages follow your Jellyfin account; change them in Jellyfin" sentence is removed.

## Proposed choices (for owner confirmation, Q1)

Every row below is backed by a P17-01 cell (`account-language-defaults.json`, same index on 10.11.7 and 12.4.0). A read state whose effect no cell shows is displayed but never offered as a choice.

### Audio row: one Picker, sets `AudioLanguagePreference` and `PlayDefaultAudioTrack`

| Choice (label) | Writes | Effect (cell) |
|---|---|---|
| The file's default | `PlayDefaultAudioTrack: true`; `AudioLanguagePreference` left as read | The file's flagged default audio track (A1, A2, A7) |
| Original language | `AudioLanguagePreference: "OriginalLanguage"`, `PlayDefaultAudioTrack: false` | On plain Jellyfin, the file's default track (A6); the original language on a server that knows it (jellyscale JS-117, JS-121, not yet built) |
| {Language}, one per language | `AudioLanguagePreference: {main three-letter code}`, `PlayDefaultAudioTrack: false` | The first audio track in that language (A3, A4, A5; `ger` finds `deu`) |

How the account's current value is shown:

| Read | Shown as |
|---|---|
| `PlayDefaultAudioTrack: true`, any language or none | The file's default (A1, A2, A7: the language has no effect) |
| `false` and `OriginalLanguage` | Original language (A6) |
| `false` and a language code | That language |
| `false` and no language, or `PlayDefaultAudioTrack` missing or not a boolean | A current-only entry "Set in another Jellyfin app" (no cell records it; not offered) |

### Subtitle row: one Picker, sets `SubtitleLanguagePreference` and `SubtitleMode`

| Choice (label) | Writes | Effect (cell) |
|---|---|---|
| Off | `SubtitleMode: "None"`; language left as read | No subtitle at the start (S4) |
| The file's default | `SubtitleMode: "Default"`; language left as read | The file's flagged default subtitle, whatever the language (S1, A1) |
| {Language}, when the audio is in another language | `SubtitleLanguagePreference: {code}`, `SubtitleMode: "Smart"` | That language when the audio differs (S5); its forced track when the audio is in it too (S6) |
| {Language}, always | `SubtitleLanguagePreference: {code}`, `SubtitleMode: "Always"` | The first full track in that language (S2, S7, S8) |

How the account's current value is shown:

| Read | Shown as |
|---|---|
| `SubtitleMode: "None"` | Off |
| `"Default"` | The file's default |
| `"Smart"` or `"Always"` with a language | The matching language entry |
| `"OnlyForced"` with a language | A current-only entry "{Language}, forced subtitles only" (S3 records it; L4 A does not list it, so it is shown but not offered) |
| `"Smart"`, `"Always"`, or `"OnlyForced"` with no language, or any other mode | A current-only entry "Set in another Jellyfin app" |

### The language list (both rows)

- From `GET /Localization/Cultures` through the existing `languageCultures` read (P17-02). One entry per main three-letter name, labelled by the first culture the server lists with it (so `zho` is "Chinese", `por` is "Portuguese", `spa` is "Spanish; Castilian"), sorted by label with `localeCompare`. An entry whose main name is not three ASCII letters (12.4.0's `qaa-qtz`) is left out. After the merge 10.11.7 gives 187 languages (192 cultures) and 12.4.0 gives 486 (494 cultures), counted from the P17-01 `cultures` fixtures; tests assert both counts.
- The value saved is the main three-letter name (`deu`), which is what the server compares (P17-01 §3).
- A saved code is matched to a language with `languageKey` (P17-02), so `ger` shows as German. A saved code that matches no culture gets a current-only entry labelled with the code as saved.
- Order in each Picker: the fixed choices first (audio: The file's default, Original language; subtitles: Off, The file's default), then the languages. In the subtitle Picker each language's two entries are adjacent, "when the audio is in another language" first. A current-only entry, when present, comes first. The Picker opens on the selected entry, and typeahead jumps by label (`picker.tsx` `typeaheadIndex`).

## Approach

### 1. Gateway

`account-languages.ts` (pure):

```ts
export class AccountConfigurationUnreadable extends Error {}

// The four fields the Languages rows show. Anything missing or of the wrong type is left out.
export function toAccountLanguageSettings(configuration: unknown): AccountLanguageSettings;

// The read Configuration with only the change's keys set. Every other key, known or not, is kept as read.
export function withLanguageChange(configuration: Record<string, unknown>, change: AccountLanguageChange): Record<string, unknown> {
  return { ...configuration, ...change };
}
```

`toAccountLanguageSettings` reads `AudioLanguagePreference` (non-empty trimmed string, `OriginalLanguage` kept as is), `PlayDefaultAudioTrack` (boolean), `SubtitleLanguagePreference` (non-empty trimmed string), and `SubtitleMode` (any non-empty string; the domain decides what it means). It returns only those keys.

`gateway.ts`, beside `accountLanguages`:

```ts
private accountWrite: Promise<unknown> = Promise.resolve();

// The account's four language fields for Settings, from GET /Users/Me.
async accountLanguageSettings(signal?: AbortSignal): Promise<AccountLanguageSettings> { … get("/Users/Me") … }

// Jellyfin replaces the whole Configuration on save (P17-01), so read it fresh, change only the row's fields,
// and post every other field back as read. Saves run one at a time.
saveAccountLanguages(change: AccountLanguageChange): Promise<AccountLanguageSettings> {
  const run = this.accountWrite.then(async () => {
    this.requireSession();
    const { data } = await this.get<UserDto>("/Users/Me", { timeout: CONTROL_REQUEST_TIMEOUT_MS });
    const configuration = isPlainRecord(data) ? data.Configuration : undefined;
    if (!isPlainRecord(configuration)) throw new AccountConfigurationUnreadable("Jellyfin returned no account configuration.");
    const next = withLanguageChange(configuration, change);
    await this.post("/Users/Configuration", next, { timeout: CONTROL_REQUEST_TIMEOUT_MS });
    return toAccountLanguageSettings(next);
  });
  this.accountWrite = run.catch(() => undefined);
  return run;
}
```

- `AccountLanguageChange` is a type that allows only the four owned keys, so a caller cannot add another field.
- No `AbortSignal` on the save: leaving Settings must not abandon a write half-way. The read inside the save has no signal for the same reason.
- No `params` on either request: P17-01 shows `POST /Users/Configuration` without `userId` saves the caller's own settings on both versions.
- The returned settings come from the body posted (P17-01: every field reads back as sent, 204, both versions), so no third request.
- `isPlainRecord` excludes arrays.

### 2. Domain: `src/domain/account-language-choices.ts`

```ts
export type SubtitleMode = "Default" | "Always" | "OnlyForced" | "None" | "Smart";
export interface AccountLanguageSettings {
  audioLanguage?: string;            // "OriginalLanguage" kept as is
  playDefaultAudioTrack?: boolean;
  subtitleLanguage?: string;
  subtitleMode?: string;             // as the server gave it
}
export type AccountLanguageChange = Partial<{
  AudioLanguagePreference: string;
  PlayDefaultAudioTrack: boolean;
  SubtitleLanguagePreference: string;
  SubtitleMode: SubtitleMode;
}>;
export interface LanguageOption { code: string; name: string }   // main three-letter code, server's label

export type AudioChoice =
  | { value: "default"; kind: "default" }
  | { value: "original"; kind: "original" }
  | { value: `lang:${string}`; kind: "language"; language: LanguageOption }
  | { value: "current"; kind: "other-app" | "unknown-code"; code?: string };   // shown, never offered
export type SubtitleChoice = … "off" | "default" | `smart:${code}` | `always:${code}` | "current" (kind "forced-only", "other-app", "unknown-code").
```

- `languageOptions(cultures)`: dedupe by `threeLetterName` (first wins), skip names not matching `/^[a-z]{3}$/`, sort by `name.localeCompare(other, "en")`.
- `audioValueOf(settings, cultures)` and `subtitleValueOf(settings, cultures)` implement the "Shown as" tables, matching languages with `languageKey` from `src/domain/languages.ts`.
- `audioChoices(cultures, settings, { originalLanguage })` and `subtitleChoices(cultures, settings)` return the ordered lists with a current-only entry first when the value needs one.
- `audioChange(value)` and `subtitleChange(value)` return the `AccountLanguageChange` per the "Writes" columns; for `"current"` they return `undefined` (no save).
- No copy here: `languages-copy.ts` turns choices into `PickerOption` labels and descriptions.

### 3. Hook: `use-account-language-settings.ts`

- Query `accountLanguageSettingsKey(gateway)` → `gateway.accountLanguageSettings(signal)`, `gcTime: ACCOUNT_GC_TIME`, default `staleTime` (30 s), so returning to Settings shows the cached value and refreshes it.
- Cultures from P17-02's `languageCulturesKey` query (same options as `useSubtitlePreference`).
- `useMutation` with `mutationKey: [...accountLanguageSettingsKey(gateway), "save"]`, modelled on `use-flag-mutation.ts`: `onMutate` cancels the settings query, saves the previous settings, and writes the optimistic settings (only the row's fields); `onError` restores only that row's fields from the previous value, raises the failed toast (or flags the refusal or the 400-on-Original case, §4), and invalidates the settings query; `onSuccess` writes the returned settings to the settings key and `{ subtitleLanguage }` to `accountLanguagesKey(gateway)` (via a small mapper so it equals what `toAccountLanguages` would give), and raises the saved toast. Rows stay usable while a save is in flight; the gateway serializes them.
- Error kind: `(error as { response?: { status?: number } }).response?.status` (kept by `redactTransportError`): 403 or 405 → refused; 400 → failed (and, if the change had `AudioLanguagePreference: "OriginalLanguage"`, `originalLanguage` becomes false); anything else → failed. `AccountConfigurationUnreadable` → failed.

## Risks and out of scope

- **Two apps saving at once can still overwrite each other.** The fresh read narrows the window; it cannot close it without a server-side partial update or version check (backlog, "Ask jellyscale for a partial update…"; issue #178 comment). Out of scope.
- **Unrecorded effects:** a chosen audio or subtitle language that a file does not have (no P17-01 cell); `PlayDefaultAudioTrack: false` with no language; Smart/Always with no language. Shown as recorded where possible and as "Set in another Jellyfin app" otherwise. Append to `tasks/backlog.md`: record a "no matching track" cell for audio and subtitles in the P17-01 recorder. S (P17-03).
- **Original language does nothing more than "The file's default" on plain Jellyfin** (A6, A7). The description says so; acceptance 2 requires offering it. Its jellyscale meaning arrives with JS-117/JS-121 and P17-04.
- **Long lists on TV:** 486 languages on 12.4.0 (and twice that in the subtitle Picker if Q1 keeps two entries per language) reached with arrows only; Home/End and opening on the selected entry help. Append to backlog: page-wise jumps (PageUp/PageDown or letter rows) in the TV Picker sheet. S (P17-03).
- **Refusal lasts only while Settings is open**; reopening retries. Acceptable for a rare proxy setup.
- **`ger` vs `deu`:** the server treats them alike (A4, S7, S8); Fluster always saves the main name.
- **Remembered selections** (`RememberAudioSelections`, `RememberSubtitleSelections`) still override per item on the server and are unverified live (`ARCHITECTURE.md` §3); this task neither reads nor changes them. A viewer may see a remembered track win after a change; out of scope.
- **P17-08** will extend `AccountLanguages` with `audioLanguage`; this task adds a separate settings read and does not change `toAccountLanguages`, so the two do not collide.
- Out of scope: the jellyscale rows (P17-05), styling (P5-05), the player menus, any PlaybackInfo change, any per-computer language setting.
